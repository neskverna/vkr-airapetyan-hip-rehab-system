# ВКР: Разработка интеллектуальной системы для персонализированной реабилитации пациентов после эндопротезирования тазобедренного сустава

**Автор:** Айрапетян Виталий

## Задачи

Задачи ВКР ведутся в виде issues этого репозитория и отслеживаются на [доске проекта](https://github.com/users/neskverna/projects/1) в трёх колонках:

- **Todo**: запланировано;
- **In Progress**: в работе;
- **Done**: выполнено.

У каждой задачи указан срок выполнения (поле «Срок» на доске).
